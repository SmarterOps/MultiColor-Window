# Navbar Toggle Dark Light Theme

This project is a responsive web page featuring a navigation bar with a dark/light theme toggle. It includes a mobile-friendly menu and an interactive button.

## Features

- **Responsive Navigation Bar:** Designed with Tailwind CSS for a modern UI.
- **Dark Mode Toggle:** Users can switch between dark and light modes.
- **Mobile Menu:** A collapsible menu for smaller screens.
- **Interactive Button:** A visually appealing button with gradient and shadow effects.

## Technologies Used

- **HTML**: Page structure.
- **CSS (Tailwind CSS)**: Styling and responsiveness.
- **JavaScript**: Handles dark mode and mobile menu toggling.

## File Structure

```
|-- index.html        # Main HTML file
|-- script.js         # JavaScript functionality
|-- icon/             # Folder containing favicon
|-- README.md         # Project documentation
```

## How to Use

1. Open `index.html` in a browser.
2. Click the **theme toggle button** (🌙/☀️) to switch between dark and light mode.
3. On smaller screens, click the **menu button** (☰) to toggle the mobile navigation.
4. Click the **"Click Me"** button for an interactive effect.

## Setup and Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/your-repo/navbar-toggle-dark-light-theme.git
   ```
2. Open `index.html` in a web browser.
